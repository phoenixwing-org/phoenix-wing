# KtCodegen 来源与许可归档

## 归档基线

本包从本机 `KtAutoCode` 仓库的只读标签 `kt-codegen-0.1.0` 迁入。该标签保存 TypeScript 初稿、17 列 CSV/v4 JSON 兼容、32 个生成块、fixture、测试与中文探测文档；迁入后由 Phoenix Wing 的 `@phoenix-wing/kt-codegen` 作为共享实现继续维护。

历史仓库继续保留，不从这里复制或改写其提交历史。它既是最初 CAA MVC-C、后续 Qt/普通 C++ 扩展的行为参考，也是代码来源和许可审计证据。

## 旧实现索引

以下路径均相对于 `KtAutoCode@kt-codegen-0.1.0`：

| 历史文件 | 迁移时采用的权威内容 |
| --- | --- |
| `KtaAutoCodeBase/KevinCAAFileGuide.vb` | Parameter 聚合、32 个块的分派与 CAA/Qt/C++ 代码生成行为 |
| `KtaAutoCodeBase/KevinCAAParamInfor.vb` | 单条参数字段、默认值与类型辅助规则 |
| `KtaAutoCodeBase/KevinControlID.vb` | 0～31 的旧生成块枚举顺序 |
| `KtaAutoCodeBase/KevinControlWords.vb` | Start/End 自动代码标记文本 |
| `KtaAutoCodeBase/KevinCAACreateItemModify.vb` | 待修改文件、标记位置与命中次数模型 |
| C++ `KtaControlConfigData` / `KtaControlConfigItem` | JSON 数据载体和 17 列 CSV 对应结构 |
| Qt `KtdAutoCodeParam` / `KtdAutoCodeItem` | 对话框、表格与共享 Parameter 的消费方式 |

具体方法与生成块的对应关系保留在本目录其余中文迁移文档和 golden fixtures 中。文档以“归档旧实现”为行为依据，但不使用跨仓库相对链接，避免 npm tarball 或独立 checkout 中出现失效链接。

## 许可边界

`@phoenix-wing/kt-codegen` 随 Phoenix Wing 按 Apache License 2.0 发布，包内包含 `LICENSE` 与 `NOTICE`。旧仓库和本地归档标签用于追溯来源；未来宿主只通过稳定 npm exports 集成，不在运行时读取相邻 Git 仓库。

当前迁移只建立纯 TypeScript 数据、兼容、Analyze 与 Renderer 契约，不包含真实源码 Apply、宿主文件 IO 或产品 UI。`kt-auto-code` 与 `phoenix-desk-tools` 的接入应在各自独立任务中完成。
