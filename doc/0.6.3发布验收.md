## 新增受控懒加载契约

0.6.3 同时导出 `PnwGitLazyHistoryState` 及以下纯 Core API：

- `pnwCreateGitLazyHistoryState`：只接收 summary 已读取的 HEAD 与最新一条 commit，
  默认收缩；
- `pnwSetGitLazyHistoryExpanded`：每次从收缩变为展开都按当前游标规划 `limit=1` 的
  exclusive OID page，同一次展开或重绘不重复规划；
- `pnwRequestGitLazyHistoryPage`：展开后只接受 1 或 5；
- `pnwApplyGitLazyHistoryPage`：追加并拒绝 stale HEAD 或重复 OID；
- `pnwFailGitLazyHistoryRequest`：失败后保留游标供 Host 显式重试。

该状态只规划请求，不直接读取 Git。Host 只有拿到 request 时才调用
`pnwReadGitCommitPage`，因此收缩状态没有第二次 Git I/O；UI Block、AbortController、
错误提示与持久化不进入 git-core。
