# Phoenix Wing 0.4.0 阻断与 0.4.1 npm 修复验收

验收日期：2026-07-17

## 结论

`phoenix-wing@0.4.0` 已存在于 npm registry，但制品**不能被干净消费者安装**，继续保留为失败发布证据。不可覆盖的缺陷已由新锁步版本 `0.4.1` 修复：八个发布物全部可从 Registry 查询，聚合包依赖不含 `workspace:`，npm/pnpm 干净安装和三个真实消费者回归均通过。

## 0.4.1 修复验收

- 本地注释标签 `0.4.1` 指向发布提交 `ce400d1`。
- `@phoenix-wing/code-core`、`kt-codegen`、`cad-contracts`、`cad-core`、`workspace-schema`、`db-node`、`cad-rust-source` 与聚合包 `phoenix-wing` 均已公开发布为 `0.4.1`。
- Registry 中聚合包的运行时依赖为 `@phoenix-wing/code-core: 0.4.1`、`@phoenix-wing/db-node: 0.4.1`，不存在 `workspace:`、`link:` 或 `file:`。
- 全新临时目录中的 `npm install phoenix-wing@0.4.1 --ignore-scripts` 与 `pnpm add phoenix-wing@0.4.1 --ignore-scripts` 均通过；npm 审计为 0 漏洞。
- Wing 250 项 TypeScript 测试、36 项 Rust 测试、全工作区类型检查、8 包/5 消费者版本矩阵、npm 发布包与 Rust 源码包重编译门禁均通过。
- Open Issue 前后端精确消费 Registry `0.4.1`，123 项测试通过、5 项跳过，完整生产构建通过，归档提交为 `228a54c`。
- Auto Code 已移除 committed Wing overrides，73 个测试文件、364 项测试、双扩展类型检查与构建通过，归档提交为 `1bcc44b`。
- Desk Tools 已移除 committed Wing overrides，server 237、catdlg-core 67、web 222 项测试及类型检查、生产构建通过，归档提交为 `fbd7831`。
- 所有 package manifest 均有 `prepublishOnly` 客户端门禁：直接 `npm publish` 被拒绝，只接受会转换 `workspace:` 的 pnpm 发布流程；消费者仍可使用 npm 或 pnpm 安装。

### 干净安装失败

在不包含相邻 Wing 源码的临时 npm consumer 中执行：

```bash
npm install phoenix-wing@0.4.0 --ignore-scripts
```

实际结果：

```text
npm error code EUNSUPPORTEDPROTOCOL
npm error Unsupported URL Type "workspace:": workspace:0.4.0
```

## 原因

根文档仍指导直接执行 `npm publish`。源码 manifest 使用 pnpm `workspace:` 依赖；直接 npm 发布没有执行 pnpm pack/publish 的 workspace 版本转换。现有 `verify:package-tarballs` 已能拒绝 tarball 中残留的 `workspace:`，但发布流程绕过了该门禁。

## 修复执行结果

npm 版本不可覆盖，因此没有修补已发布的 0.4.0，而是完成新的锁步版本 `0.4.1`：

1. 所有 Wing manifests 和 `release-matrix.json` 已锁步提升到 0.4.1。
2. 完整测试、类型检查、release matrix 和 tarball 验证已通过。
3. 已使用 `pnpm publish` 按 release matrix 顺序先发布全部 scoped packages。
4. 全部 scoped packages 已由 Registry 查询并被 Auto Code、Desk Tools 的锁文件消费。
5. 聚合包 `phoenix-wing@0.4.1` 已最后发布。
6. 无相邻源码的 npm 与 pnpm 临时消费者安装已通过。
7. Open Issue 已用独立提交升级并通过测试与生产构建。0.4.0 仍建议在 npm 标记为 deprecated，但不影响 0.4.1 验收结论。

## 退出门禁

- registry 中八个发布物版本一致且均可查询。
- 任一已发布 manifest 不包含 `workspace:`、`link:`、`file:`。
- `npm install phoenix-wing@<version>` 与 `pnpm add phoenix-wing@<version>` 均通过。
- Auto-code、Desk 不依赖 committed 相邻目录 link 完成构建。
- Open Issue 使用精确 registry 版本完成测试与生产构建。

上述门禁已由 0.4.1 全部关闭。0.4.0 只保留为失败制品和回归样本，不再作为任何消费者目标。
