# npm 发布配置步骤（通过 Access Token）

> 重要：不得在仓库根直接执行 `npm publish`。0.4.0 因此发布了含 `workspace:` 的不可安装 manifest，详见[《0.4.0 发布验收》](0.4.0发布验收.md)。多包发布必须使用 pnpm、先发布 scoped packages、最后发布聚合包，并在发布后执行干净消费者安装。

## 1. 创建 Granular Access Token

1. 登录 [npmjs.com](https://www.npmjs.com)
2. 点击右上角头像 → **Access Tokens**
3. 点击 **Generate New Token** → 进入 **New Granular Access Token** 页面
4. 按以下配置填写：

### Token 基本信息

| 字段 | 值 |
|------|-----|
| Token name | 起个名字，如 `phoenix-wing-publish` |
| Description | 选填，备注用途 |

### 关键配置：Packages and scopes

| 设置 | 值 |
|------|-----|
| Permissions | **Read and write** |
| 包范围 | 选 **All packages**（或指定 `phoenix-wing`） |

### 关键配置：Bypass two-factor authentication

确保勾选 **"Bypass two-factor authentication"** 选项（此选项在页面上可能以不同形式出现，核心是让 token 发布时不需要 2FA）。

### 可选配置

| 字段 | 说明 |
|------|------|
| Allowed IP ranges | 留空即可（不限制 IP） |
| Organizations | **不选**（组织不是必须的） |
| Expiration | 按需设置过期时间 |

5. 点击 **Generate Token**，复制生成的 token（形如 `npm_xxxxxxxxxxxx`）

> ⚠️ Token 只显示一次，务必立即复制保存！

## 2. 配置本地 .npmrc

在终端执行：

```bash
npm config set //registry.npmjs.org/:_authToken <你的token>
```

或者直接编辑 `~/.npmrc`，添加：

```
registry=https://registry.npmjs.org/
//registry.npmjs.org/:_authToken=npm_xxxxxxxxxxxx
```

## 3. 验证配置

```bash
# 检查登录状态
npm whoami
# 应输出你的用户名

# 检查 token 列表
npm token list
# 应显示 Publish token
```

## 4. 发布前门禁

```bash
cd phoenix-wing
pnpm test:workspace
pnpm -r --include-workspace-root --if-present typecheck
pnpm verify:release-matrix -- --require-consumers
PNW_VERIFY_OFFLINE=1 pnpm verify:package-tarballs
pnpm verify:cad-rust-tarball
```

任何一步失败都不得发布。特别检查生成的 tarball manifest 不包含 `workspace:`、`link:` 或 `file:`。

## 5. 按矩阵顺序发布

先统一提升全部 manifests 与 `release-matrix.json` 的锁步版本。以下以 `<version>` 表示待发布的新版本：

```bash
pnpm --dir packages/code-core publish --access public --no-git-checks
pnpm --dir packages/kt-codegen publish --access public --no-git-checks
pnpm --dir packages/cad-contracts publish --access public --no-git-checks
pnpm --dir packages/cad-core publish --access public --no-git-checks
pnpm --dir packages/workspace-schema publish --access public --no-git-checks
pnpm --dir packages/db-node publish --access public --no-git-checks
pnpm --dir packages/cad-rust-source publish --access public --no-git-checks
pnpm publish --access public --no-git-checks
```

每发布一个 scoped package，立即执行 `npm view <package>@<version> version`；七个 scoped packages 全部可查询后才允许发布聚合包。禁止改回 `npm publish`。

## 6. 查看发布情况

```bash
# 查看包基本信息（版本、描述、依赖等）
npm view phoenix-wing

# 查看所有已发布版本
npm view phoenix-wing versions

# 查看最新版本号
npm view phoenix-wing version

# 查看包的 npm 页面地址
npm view phoenix-wing repository.url
```

还必须在没有相邻 Wing 源码的临时目录执行：

```bash
npm init -y
npm install phoenix-wing@<version> --ignore-scripts
```

随后用 Open Issue 或等价 registry consumer 完成测试与生产构建。仅 `npm view` 能看到版本不代表发布成功。

也可以在浏览器直接访问：https://www.npmjs.com/package/phoenix-wing

### 常见问题

| 错误 | 原因 | 解决 |
|------|------|------|
| `E403` | Token 未勾选 Bypass 2FA，或权限为 Read only | 回第 1 步检查 token 权限配置 |
| `E402` | 发布了付费包（private package） | 确认 package.json 中 `private: false` |
| Token 丢失 | 创建后未保存 | 删除旧 token，重新创建 |
