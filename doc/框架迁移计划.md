# 桌面应用壳层框架迁移计划

## ⚠️ 命名前缀

详见 **[doc/命名规则.md](命名规则.md)** — 所有新建文件必须从第一行起使用前缀。

---

## 目标

将 phoenix-desk-tools 的应用壳层（AppShell）抽象为可复用的 Vue3 框架，放入 phoenix-wing，
供其他项目快速搭建类似架构的应用。

## 架构分析

phoenix-wing 壳层采用经典 IDE 布局，详见 **[doc/架构图.md](架构图.md)**。

## 分层策略

## 迁移步骤

### Phase 1: 纯框架组件（无业务依赖，可直接搬）

1. **SidebarBlock + SidebarBlockHead** ✅ 最简单
2. **Ribbon 按钮组件**（TabBar, Group, ToolButton, UtilButton）
3. **RibbonShell + RibbonPanel**（需先剥离业务逻辑）
4. **WorkbenchTabBar**（依赖 useWorkbench）
5. **PageHeader**（移除 PageHelpButton 依赖）

### Phase 2: Composables（需少量接口抽象）

1. **useWorkbench** — 移除 CAA/EPHEMERAL_TAB_PAGES 引用
2. **pagePropertiesHost + usePagePropertySheet** — 依赖 Pnw 类型，已就绪
3. **useDocumentTitle** — 参数化标题格式
4. **shellUrlSync** — 接口化 ShellUrlIntent
5. **sideDockLayout** — 纯数学，无需改动
6. **useResizableTable** — 零依赖，直接搬

### Phase 3: 欢迎页骨架

1. 提取 WelcomeShell 组件
2. 将品牌/操作/列表 slot 化
3. 移除 CAA 草稿面板

### Phase 4: desk-tools 适配

1. 将 desk-tools 的 layout/ 改为从 phoenix-wing 引用
2. 保留 desk-tools 自己的业务组件（WorkspaceTreeSidebar, AppToolbar, StatusBar 等）
3. 验证 build

## RibbonConfig 抽象方案

保留类型定义，数据由消费项目提供：

```ts
// phoenix-wing: src/types/ribbonConfig.ts
export interface PnwRibbonItemDef {
  id: string
  label: string
  pageId?: string
  icon?: Component
  tooltip?: string
  module?: string
  initChecked?: boolean
  action?: () => void
}

export interface PnwRibbonGroupDef {
  id: string
  label: string
  layout?: "group" | "inline"
  items: PnwRibbonItemDef[]
}

export interface PnwRibbonTabDef {
  id: string
  label: string
  shortcut?: string
  groups: PnwRibbonGroupDef[]
  // isShell?: boolean  — 是否为壳层常驻 Tab
}

// 消费项目提供实例:
// const MY_RIBBON_TABS: PnwRibbonTabDef[] = [...]
// <RibbonShell :tabs="MY_RIBBON_TABS" ... />
```

类似地，`ribbonIcons.ts` 改为接受 `Record<string, Component>` 注入。
