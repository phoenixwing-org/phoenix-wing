# 快速使用

```bash
npm install phoenix-wing vue pinia
```

聚合 UI 从编译后的 `dist` 单入口加载。新代码优先使用下列根入口命名导出；0.4.x 仍保留 `.vue` 子路径作为兼容入口，两种写法解析到同一模块实例。

## 工具函数

```ts
import {
  pnwFormatDuration,
  pnwScheduleDebounced,
  pnwBindPointerDrag,
  pnwResolveColorScheme,
  pnwClearPhoenixBrowserStorage,
} from 'phoenix-wing'
```

## 确认对话框

```ts
import { pnwPromptChoice } from 'phoenix-wing'

const result = await pnwPromptChoice({
  title: '确认删除',
  message: '此操作不可撤销',
  choices: [
    { id: 'delete', label: '删除', variant: 'danger' },
    { id: 'cancel', label: '取消' },
  ],
})

if (result.choiceId === 'delete') {
  // 执行删除
}
```

## Ribbon 工具栏

```ts

  PnwRibbonShell,
  PnwRibbonTabBar,
  PnwRibbonGroup,
  PnwRibbonToolButton,
} from 'phoenix-wing'
```

维护旧代码时仍可使用 `phoenix-wing/components/PnwAppModalOverlay.vue` 或 `phoenix-wing/layout/PnwPageHeader.vue`，无需一次性迁移。

## 工作台引擎

```ts
import { pnwCreateWorkbench } from 'phoenix-wing'

const wb = pnwCreateWorkbench({
  pagePolicy: (pageId) => ({ maxTabs: 1, tabEnabled: true }),
  navLabel: (pageId) => pageId,
})

wb.openTab({ pageId: 'my-page', title: '我的页面' })
```
