# Phoenix 三库版本矩阵

机器可读真源为仓库根目录的 [`release-matrix.json`](../release-matrix.json)。Wing 单仓 CI 运行 `pnpm verify:release-matrix -- --wing-only`；四仓同目录联调运行 `pnpm verify:consumers`，后者要求所有消费者 manifest 都存在。

> 发布状态：0.4.0 是含未转换 `workspace:` 的失败制品；锁步修复版本 0.4.1 已完成八包发布、Registry manifest、npm/pnpm 干净安装和 Open Issue、Auto Code、Desk Tools 真实消费验收，详见[《0.4.0 阻断与 0.4.1 修复验收》](0.4.0发布验收.md)。

> 上一消费基线：Wing 0.4.2 八个发布单元已公开发布；Open Issue `e86fe3d`、Auto Code `febcaf4` 与 Desk Tools `411d27c` 已全部精确升级并通过 Registry fixture、测试和生产构建。发布与消费证据见[《0.4.2 本地发布候选验收》](0.4.2发布候选验收.md)。

> 当前 Wing 版本：0.4.3 八个发布单元已通过 pnpm 锁步公开发布，Registry `latest` 均为 0.4.3；注释标签 `0.4.3` 已封签到最终候选 `5211504` 并推送远端。Auto Code、Desk Tools 与 Open Issue 仍精确消费 0.4.2，尚未把消费者升级结果计入完成态。门禁与回执见[《0.4.3 发布与消费验收》](0.4.3发布候选验收.md)。

## 0.4.x 锁步发布单元

| 发布物 | 消费方 | 约束 |
| --- | --- | --- |
| `@phoenix-wing/code-core` | KT Auto Code、Desk server | 纯 TS；不得带入 Vue/Element/SQLite/Rust |
| `@phoenix-wing/kt-codegen` | KT Auto Code、Desk Tools | 纯 TS；共享 Parameter、legacy、marker、Analyze/Renderer 与 Apply 投影；不含文件系统/UI |
| `@phoenix-wing/cad-contracts` | KT Auto CAD、Desk server | native/provider/query 协议与无驱动只读查询共同真源 |
| `@phoenix-wing/cad-core` | KT Auto CAD、Desk server | 纯 CAD 计算 |
| `@phoenix-wing/workspace-schema` | KT Auto CAD、Desk server | workspace Schema v13 与固定 DDL 哈希 |
| `@phoenix-wing/db-node` | Desk server | Node SQLite adapter；不得进入 VSIX |
| `@phoenix-wing/cad-rust-source` | Desk 构建阶段 | Rust 源码；不得进入 VSIX或运行时安装脚本 |
| `phoenix-wing` | Desk web-ui 与旧消费者 | Vue/UI 聚合兼容包；Code/CAD 新代码不再依赖 |

Wing 源码 manifests 与 npm Registry 八包当前统一为 `0.4.3`，全部消费者仍为 `0.4.2`。发布已按“纯 TS/契约/Schema → Node adapter → Rust source → 聚合兼容包”完成；机器矩阵继续登记 Auto workspace/双 VSIX、Desk server/web 与 Open Issue server/web 的真实版本，后续逐仓升级消费者并独立验收，不提前改写完成态。

协议主版本独立于 npm 版本：KtCodegen Plan v1、Ribbon contribution v1、CAD native v1、CAD query v1、native provider v1、workspace Schema v13。协议不兼容时宿主必须阻止调用，不能用 npm 版本猜测兼容；canonical fixture 由 Wing 随包发布，消费仓直接导入 Registry fixture，只验证 adapter 与字节一致性。
