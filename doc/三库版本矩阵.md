# Phoenix 三库版本矩阵

机器可读真源为仓库根目录的 [`release-matrix.json`](../release-matrix.json)，校验入口为 `pnpm verify:release-matrix -- --require-consumers`。

> 发布状态：0.4.0 是含未转换 `workspace:` 的失败制品；锁步修复版本 0.4.1 已完成八包发布、Registry manifest、npm/pnpm 干净安装和 Open Issue、Auto Code、Desk Tools 真实消费验收，详见[《0.4.0 阻断与 0.4.1 修复验收》](0.4.0发布验收.md)。

> 当前候选：Wing 八个发布单元已锁步准备 0.4.2；在公开发布和三仓 Registry 升级前，`release-matrix.json` 仍明确校验消费者的已发布基线 0.4.1，不把本地候选误记为可消费版本。候选门禁见[《0.4.2 本地发布候选验收》](0.4.2发布候选验收.md)。

## 0.4.2 锁步发布单元

| 发布物 | 消费方 | 约束 |
| --- | --- | --- |
| `@phoenix-wing/code-core` | KT Auto Code、Desk server | 纯 TS；不得带入 Vue/Element/SQLite/Rust |
| `@phoenix-wing/kt-codegen` | KT Auto Code、Desk Tools | 纯 TS；共享 Parameter、legacy、marker、Analyze/Renderer 与 Apply 投影；不含文件系统/UI |
| `@phoenix-wing/cad-contracts` | KT Auto CAD、Desk server | native/provider/query 协议与无驱动只读查询共同真源 |
| `@phoenix-wing/cad-core` | KT Auto CAD、Desk server | 纯 CAD 计算 |
| `@phoenix-wing/workspace-schema` | KT Auto CAD、Desk server | workspace Schema v13 与固定 DDL 哈希 |
| `@phoenix-wing/db-node` | Desk server | Node SQLite adapter；不得进入 VSIX |
| `@phoenix-wing/cad-rust-source` | Desk 构建阶段 | Rust 源码；不得进入 VSIX或运行时安装脚本 |
| `phoenix-wing` | Desk web-ui 与旧消费者 | Vue/UI 聚合兼容包；Code/CAD 新代码不再依赖 |

所有 Wing 发布物本期统一准备 `0.4.2`，发布顺序固定为“纯 TS/契约/Schema → Node adapter → Rust source → 聚合兼容包”。公开发布前必须通过版本矩阵、TypeScript/Rust tarball、干净 npm/pnpm consumer 和本地标签门禁；公开发布后再升级 Open Issue、Desk 与双扩展，并把 `release-matrix.json` 的消费者基线从 0.4.1 切到 0.4.2。

协议主版本独立于 npm 版本：KtCodegen Plan v1、Ribbon contribution v1、CAD native v1、CAD query v1、native provider v1、workspace Schema v13。协议不兼容时宿主必须阻止调用，不能用 npm 版本猜测兼容；canonical fixture 由 Wing 随包发布，消费仓只验证 adapter 与字节一致性。
