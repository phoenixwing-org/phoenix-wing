# Phoenix Wing 0.6.0 发布验收

状态：current（已公开发布）

Owner：Phoenix Wing maintainers

适用版本：0.6.0

最后核验：2026-07-31

## 发布结论

Phoenix Wing **0.6.0** 已于 2026-07-31 按锁步矩阵公开发布。该版本保持
0.5.1 公共入口兼容，并新增可复用的 Vue Web 工作台、公共图标与诊断 Block，
同时提供 Git 轻量仓库摘要、OID 游标分页和只读取消能力。

本发布记录只维护 Wing 自身版本、制品和 Registry 事实。具体消费者的依赖升级、
运行页面结果和产品适配由各消费者仓库或跨仓 AI Workspace 独立记录。

- `pnpm docs:check`：67 篇 Markdown 分类和 current 链接通过；
- `pnpm verify:architecture`：172 个源码文件、9 个纯依赖图和 3 个 View root 通过；
- 聚合构建、声明输出和 11 个关键 dist 入口检查通过；
- 12 包 release matrix 通过；
- 全 workspace TypeScript、Vitest 与 Rust 测试通过；
- 全 workspace 类型检查通过；
- 10 个小包与聚合 UI 的 tarball 干净 npm/Vite 消费通过；
- `cad-rust-source` tarball 在临时目录完成 release 重建、协议、query 和 doc tests。

首次在受限进程内执行两个 npm tarball 门禁时，本机 npm cache 写权限返回
`EPERM`；在允许访问既有 cache 的发布环境重跑后全部通过。没有修改 cache
所有权，也没有绕过任何发布门禁。
