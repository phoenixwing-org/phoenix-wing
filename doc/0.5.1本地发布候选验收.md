# Phoenix Wing 0.5.1 发布验收

状态：current（已公开发布）

Owner：Phoenix Wing maintainers

适用版本：0.5.1

最后核验：2026-07-23

## 发布结论

Wing **0.5.1** 是 0.5.0 之后的向后兼容补丁发布，新增共享编辑抽屉宿主：

- `PnwEditorDrawerHost` 统一左右侧抽屉、响应式宽度、内容容器和可选头部/工具栏/Footer；
- `PnwEditorDrawerCloseContext` 与 `PnwEditorDrawerCloseGuard` 统一 `view` / `create` / `edit` 模式、dirty 关闭保护和编辑身份；
- Function 通过受控本地 Wing 模式完成首个真实消费者接入，两处详情抽屉不再直接使用 `el-drawer`；
- 发布前的消费者验证保持 Registry 依赖，未写入 `link:`、`file:`、workspace override，也未修改消费者 `node_modules`。

## 锁步范围

根包、11 个 scoped 包、内部 `workspace:` 版本、`release-matrix.json`、Rust source manifest、`fcstd-query` crate、Cargo lock 和 `PNW_VERSION` 统一为 `0.5.1`。

## 本地门禁

候选归档前必须完成：

1. `pnpm verify:release-matrix`；
2. `pnpm verify:ci`；
3. Function 普通 Registry 模式 Vite 构建；
4. Function 受控本地 Wing 模式 Vite 构建；
5. Function 两处编辑抽屉的浏览器打开、响应式和 dirty 关闭保护检查；
6. 两库工作树与提交记录点检。

## 发布记录

- 12 个 Wing 发布物已按依赖顺序公开发布到 npm，Registry `latest` 均为 `0.5.1`。
- 发布完成后，开发分支将合并到 `master`，并在合并结果创建注释标签 `0.5.1`。
- 消费者的精确依赖版本、锁文件和后续 Registry 验证由各消费仓库独立维护；Wing 不再回写具体消费者版本矩阵。
- Open Issue 是否升级由其仓库独立决定。

## 验收回执

- `PNW_VERIFY_OFFLINE=1 pnpm verify:ci` 已通过：文档、架构、聚合构建与导出、12 包版本矩阵、全 workspace 测试与类型检查、干净 npm/Vite tarball 消费、Rust source release 编译与契约测试全部完成。
- 全量门禁发现并修复了 0.5.0 后归档提交造成的既有 fixture 漂移：C++ constructor-less excerpt 的 parity 哈希、KtCodegen 被误删的 legacy CSV，以及被改成生成结果的 legacy/apply 输入 fixture；未修改对应生产算法。
- Function 普通 Registry 0.4.3 模式和受控本地 Wing 0.5.1 模式均完成 Vite 生产构建；普通模式没有缺失导出告警，本地模式实际打入 `PnwEditorDrawerHost`。
- 浏览器在真实登录态下验证 `FunctionList` 与 `FunctionCards` 两处实例均为 `data-pfd-editor-host-source="wing"`，携带各自 `pageId`、`edit` 模式和 `resourceKey`。
- 响应式测量：553px 视口抽屉宽 553px；1200px 视口抽屉宽 1020px（85%）。
- 两处编辑抽屉都通过 Escape dirty 关闭保护；Cancel 保持编辑，OK 关闭，测试未保存或改写业务数据。
- Function `vue-tsc -b` 仍报告既有 16 项基线错误，本次新增适配层没有引入新错误；Vite 和浏览器运行无新增错误。
- 0.5.1 已完成 npm 公开发布；Function 的 Registry 升级和第二个消费者验证留在各消费仓库独立完成。
