# Phoenix Wing 0.4.2 本地发布候选验收

状态：current

Owner：Phoenix Wing maintainers

适用版本：0.4.2

最后核验：2026-07-17

## 候选范围

0.4.2 是八个 npm 发布单元的锁步候选，承载以下已完成的 Wing 侧能力：

- 聚合 UI 改为编译制品统一入口，根入口与兼容子路径共享同一 Vue/Pinia 状态实例，并自动加载样式。
- KtCodegen Plan v1、Ribbon contribution v1 与 workspace Schema compatibility v1 形成跨宿主 fixture 和显式版本拒绝门禁。
- UUID/GUID 格式保持与 workspace path 匹配形成 `code-core` 两项纯能力；`pure-capabilities-v1.json` 随包发布。
- KtCodegen Renderer 的 32 个 block 已拆入 10 个命名 family，注册表保证唯一归属。

## 本地归档门禁

公开发布前必须同时成立：

1. 八个 `package.json`、Rust source manifest、`fcstd-query` crate 与 `release-matrix.json` 均为 0.4.2。
2. `pnpm verify:ci` 全绿，覆盖文档、AST 依赖方向、构建、聚合单例、版本矩阵、全 workspace 测试/类型检查、TypeScript 与 Rust tarball。
3. 干净 tarball consumer 能导入 `pure-capabilities-v1.json`，并执行 UUID 与 workspace path smoke；聚合包不得泄漏源码或 `workspace:`。
4. 发布提交工作树干净，创建本地注释标签 `0.4.2`；标签存在后才允许请求公开发布确认。
5. 发布必须使用 pnpm；直接 `npm publish` 由 `prepublishOnly` 拒绝，防止 `workspace:` 依赖未经转换进入 Registry。

## 尚未完成的外部事实

本页不声明 0.4.2 已公开。npm Registry 发布、Registry manifest 查询、全新 npm/pnpm 安装以及 Auto Code、Desk Tools、Open Issue 升级都属于发布后验收。完成前，三个消费者继续精确使用已验证的 0.4.1；完成后再更新版本矩阵和本页状态。
