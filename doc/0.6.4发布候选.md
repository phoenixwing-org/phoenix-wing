# Phoenix Wing 0.6.4 发布候选

状态：current（本地候选，未发布）

Owner：Phoenix Wing maintainers

适用版本：0.6.4

最后核验：2026-08-10

## 范围

0.6.4 是向后兼容的 UI patch。`PnwPrimarySection` 的折叠箭头默认位于标题左侧，
遵循 VS Code 习惯：收起时向右、展开时向下。点击区域、键盘操作、`aria-expanded`、
受控与非受控状态以及 120ms 动画保持不变；消费者不应再写位置特例。

## 独立版本身份

本轮实际发布集合只有根 `phoenix-wing@0.6.4`。`PNW_VERSION` 与根包一致为 0.6.4；
11 个 scoped packages、Rust source 身份及其实现均保持已发布的 0.6.3。根包内部
依赖继续精确使用 `code-core@0.6.3` 与 `db-node@0.6.3`。该边界遵循
[《独立版本发布规则》](独立版本发布规则.md)，不会为未变化 Core 产生空 patch。

## 发布前门禁

- [x] 文档、架构边界、聚合 dist 与逐包 release matrix 检查通过。
- [x] 根包和 workspace 测试、类型检查、生产构建通过。
- [x] 根聚合包 tarball、内部 0.6.3 精确依赖和完整工作区回归通过；Rust source 只做
  不变性回归，不进入发布集合。
- [ ] Admin 真实消费者验证 Primary Section 左侧箭头、明暗主题和宽窄屏。
- [ ] 发布后在无相邻源码的干净 Registry consumer 中核对 `PNW_VERSION === "0.6.4"`
  且根依赖仍解析为 0.6.3。

本文件不授权 publish、Git tag 或 push；这些操作必须在候选门禁完成后单独执行。
