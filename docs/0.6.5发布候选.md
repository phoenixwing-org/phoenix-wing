# Phoenix Wing 0.6.5 发布候选

状态：current

Owner：Phoenix Wing maintainers

适用版本：0.6.5

最后核验：2026-08-14

## 候选范围

0.6.5 是根 Vue/UI 包的向后兼容功能候选，新增受控的可浮动 / Primary 停靠工具宿主。
根 `phoenix-wing` 从 0.6.4 提升到 0.6.5；11 个未变化的 `@phoenix-wing/*` scoped
packages 继续保持 0.6.3，根包对 `code-core` / `db-node` 的精确内部依赖也保持 0.6.3。

本轮实际候选集合只有 `phoenix-wing@0.6.5`，当前为本地候选，**未发布、未 push、未打
tag**。是否发布必须等待开发者再次明确授权。

## 公共能力

- `PnwDockableToolDefinition / State / Command`；
- `PNW_DEFAULT_DOCKABLE_TOOL_STATE`；
- `pnwNormalizeDockableToolState / pnwReduceDockableToolState`；
- `pnwIsDockableToolVisible`；
- `PnwDockableToolWindow / PnwDockablePrimarySection`；
- `PnwIcon` 新增 `window-float` 公共图标；
- `zh-CN / en-US` 停靠、浮出、首尾与关闭文案。

契约、状态机、作用域、Host availability 与持久化边界见
[《Pnw 工作台 Web · 可浮动与 Primary 停靠工具宿主》](Pnw工作台Web可浮动与Primary停靠工具宿主.md)。

## 验收

- [x] `closed / floating / primary` 互斥状态转换；
- [x] mode 切换保留坐标、Primary 首尾和折叠状态；
- [x] `application` 跨 View，`view` 离开 owner 只暂时隐藏并可恢复；
- [x] 浮窗拖动位置通过受控状态回传；
- [x] 浮窗停靠，Primary 浮出、首尾、折叠和 X 关闭；
- [x] 浮窗复用 Teleport overlay light/dark theme；
- [x] SSR/DOM/a11y、类型、构建、工作台 fixture 与文档门禁；
- [x] OpticalTool 在其 `codex/view-prototype` worktree 完成本地源码 API 接入与联合验收；
- [x] 根包及工作区 tarball / 无相邻源码 clean consumer 最终复验；
- [ ] 开发者明确授权后才允许 Registry 发布。

## 发布时仍需核对

1. `release-matrix.json` 仅根包为 0.6.5，11 个 scoped packages 保持 0.6.3；
2. pack manifest 不含 `workspace:`、`file:`、`link:`，内部依赖转换为精确 0.6.3；
3. clean consumer 可导入 `PNW_VERSION === "0.6.5"`、两个组件、状态机和类型；
4. Registry exact `phoenix-wing@0.6.5` 未被占用；
5. 实际发布、push 和 tag 均需单独授权。
