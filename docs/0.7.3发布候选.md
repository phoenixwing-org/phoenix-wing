## 2. 候选能力边界

- `PnwCombo` 管理受控候选、删除和清空意图；真实持久化仍由 Host 负责。
- 清理能力坚持 preview/execute 两阶段、冻结路径身份、取消协作、符号链接与文件系统根保护；
  对话框只负责交互，不绕过 Node provider 的执行前复验。
- Git 提交图仍是只读分页。`date-order` 让并行分支按提交者时间交错，同时保证子提交先于父提交；
  旧 v1 cursor 不可续读，Host 必须清空旧页并重开。
- Codegen 继续由 Host 持有文件、草稿和写盘授权；Wing 只提供纯 TS 计划、表格与 Primary 交互。
- 根 Header 调整不改变 Host 的 View 路由、关闭、停靠或持久化责任。
