# Phoenix 三库版本矩阵

机器可读真源为仓库根目录的 [`release-matrix.json`](../release-matrix.json)，分别固定
每个 Wing 发布物的精确版本与协议主版本。Wing 单仓 CI 运行
`pnpm verify:release-matrix`。消费者的精确依赖版本、锁文件与验收门禁由各自仓库
维护。0.6.4 起默认采用[按包独立版本](独立版本发布规则.md)。

> 历史发布状态：0.4.0 是含未转换 `workspace:` 的失败制品；锁步修复版本 0.4.1 已完成八包发布、Registry manifest、npm/pnpm 干净安装和多个消费者验收，详见[《0.4.0 阻断与 0.4.1 修复验收》](releases/0.4.0发布验收.md)。

> 历史消费基线：Wing 0.4.2 八个发布单元已公开发布，三个消费者已精确升级并通过 Registry fixture、测试和生产构建。发布与消费证据见[《0.4.2 本地发布候选验收》](releases/0.4.2发布候选验收.md)。

> 2026-09-14 已正式发布 **phoenix-wing@0.7.5**，Registry exact 与 `latest` 均核验为 `0.7.5`；
> scoped packages 未重复发布，继续按 `release-matrix.json` 保持各自独立版本，
> 包括 `code-core@0.6.6` 与 `kt-codegen@0.6.6`。0.7.5 结果见
> [《0.7.5 发布验收》](releases/0.7.5发布验收.md)，0.7.4 Registry 回执见
> [《0.7.4 发布验收》](releases/0.7.4发布验收.md)。

## 当前独立发布单元

0.8.0 已于 2026-10-07 正式发布，见 [0.8.0 发布验收与回执](releases/0.8.0发布候选.md)。2026-10-20 当前源码准备 [0.8.1 本地候选](releases/0.8.1发布候选.md)，尚未发布。下表是当前源码版本；仅根包、code-core 与 run-node 为本轮新候选，不是这些新版本的 Registry 可用性声明。

| 发布物 | 源码版本 | 消费方 | 约束 |
| --- | --- | --- | --- |
| `@phoenix-wing/code-core` | 0.6.8 | 代码工具宿主 | 纯 TS；不得带入 Vue/Element/SQLite/Rust |
| `@phoenix-wing/git-core` | 0.6.4 | Git 工具宿主 | 纯 TS Git 摘要、连续历史与改写计划 |
| `@phoenix-wing/git-node` | 0.6.5 | Git 工具宿主 | Node 22 Git CLI、仓库读取与隔离 worktree 事务 |
| `@phoenix-wing/run-core` | 0.6.4 | Run 工具宿主 | 纯 TS Run 项目/目标、CAA/CMake 分类与平台计划 |
| `@phoenix-wing/run-node` | 0.6.5 | Run 工具宿主 | Node 22 目标发现、Task 导入、launch plan 与受控清理 |
| `@phoenix-wing/kt-codegen` | 0.6.6 | 代码生成宿主 | 纯 TS；共享 Parameter、legacy、marker、Analyze/Renderer、Apply 投影及 Host-neutral 表格/Primary 组件；不含文件系统与 Host API |
| `@phoenix-wing/cad-contracts` | 0.7.0 | CAD 宿主 | native/provider/query、共享索引事务与重置契约 |
| `@phoenix-wing/cad-core` | 0.7.0 | CAD 宿主 | 纯 CAD 计算、XML 投影与索引规划 |
| `@phoenix-wing/workspace-schema` | 0.6.3 | 工作空间数据宿主 | workspace Schema v13 与固定 DDL 哈希 |
| `@phoenix-wing/db-node` | 0.6.3 | Node 数据宿主 | Node SQLite adapter；不得进入 VSIX |
| `phoenix-wing` | 0.8.1 | Vue 工作台宿主 | Vue/UI 聚合兼容包；Code/CAD 新代码不再依赖 |

当前根包内部依赖精确指向 `code-core@0.6.8` 与既有 `db-node@0.6.3`；本轮仅准备根包 0.8.1、code-core 0.6.8 与 run-node 0.6.5 三个新候选，其他八个发布单元不产生空 patch。表中消费方使用中性的能力类别；Registry 公开状态与消费者当前精确版本仍以实际查询及各消费仓库自己的 manifest、lockfile 和依赖门禁为准，不回写 Wing。

本地归档、候选版本声明与旧门禁回执均不代表正式发布。新增 Primary 动态宽度目标及升版后的完整测试、实际 tarball、隐私和干净消费者验收以本轮候选回执为准；尚未完成的项目不得标为通过。Codegen 规则保持 1.0.2。

协议主版本独立于 npm 版本：KtCodegen Plan v1、Ribbon contribution v1、CAD native v1、CAD query v1、native provider v1、workspace Schema v13。协议不兼容时宿主必须阻止调用，不能用 npm 版本猜测兼容；canonical fixture 由 Wing 随包发布，消费仓直接导入 Registry fixture，只验证 adapter 与字节一致性。
