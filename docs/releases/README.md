# 发布记录

这里集中维护每个版本的候选、验收和正式发布回执；不存放运行时 API 说明。

## 使用约定

- 新版本文档统一创建在本目录，命名为 `<版本>发布候选.md` 或 `<版本>发布验收.md`。
- 同一版本尽量维护一份连续记录：候选阶段写明待验项目，正式发布后补充源码节点、发布集合、命令、Registry 校验值与干净消费者结果，不另复制一份候选正文。
- 文件名中保留“候选”的历史记录不等于尚未发布；以正文的状态和 Registry 回执为准。本次归类不重写历史验收结论。
- 通用[发布步骤](../发布配置步骤.md)、[独立版本规则](../独立版本发布规则.md)、[版本矩阵](../三库版本矩阵.md)留在上一级。
- 移动或新增记录后，同步本索引、相关链接和文档分类，运行 `pnpm docs:manifest`、`pnpm docs:check` 与 `git diff --check`。日志中的本机路径、凭据和私人消费者信息不进入公开回执。
