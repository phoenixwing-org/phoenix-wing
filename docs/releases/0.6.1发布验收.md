# Phoenix Wing 0.6.1 发布验收

状态：current（已公开发布）

Owner：Phoenix Wing maintainers

适用版本：0.6.1

最后核验：2026-08-02

## 候选范围

0.6.1 是 0.6.0 的向后兼容工作台增量。12 个 npm 发布单元、内部精确依赖、
`release-matrix.json` 与 `PNW_VERSION` 锁步提升到 0.6.1。

本轮新增：

1. `PnwWorkbenchShell / PnwWorkbenchLayout` 受控 `editorMaximized` 与更新事件；
   TabBar 提供最大化/还原，Escape 还原，显示偏好和面板尺寸不被改写；
2. `PnwWorkbenchTabBar / Shell` 的 `canRefreshActiveTab`、
   `canCloseOtherTabs` 与 `refreshActiveTab / closeOtherTabs` 通用信号；
3. Host 驱动的 `PnwLocale = "zh-CN" | "en-US"`，覆盖工作台设置、标签动作、
   布局句柄、Footer、浮动面板与相关无障碍文案；
4. `PNW_WORKBENCH_OVERLAY_LAYERS`、`PnwFloatingPanel.layer / zIndex` 与 CSS token
   组成的叠层契约，保证 Host 工具高于 Wing 设置面板；
5. 公共 `refresh / close-others / editor-maximize / editor-restore` 图标能力，原有图标
   和组件入口保持兼容；
6. 规范 `PnwIconId`、保留的 `pnw` namespace、Host 图标白名单与统一
   `PnwIconRenderer`。新持久化值必须写成 `pnw:dashboard` / `cool:folder`，未知 ID
   显示 `unknown` fallback；旧裸名称、Vue Component 与 pageId 注册仍可运行；
7. Ribbon 工具 normal / hover / active 分别使用次级、主前景与活动语义色；内置
   `pnw:*` 保持 24×24、1.75 描边，Wing 不用全局 CSS 改写 Host SVG 线重或填充。

产品 Router、Process、KeepAlive、语言持久化、标签刷新实现、返回/主页/产品链接仍由
Host 持有。最大化不是 View contribution，也不进入
`PnwWorkbenchDisplayPreferences`。

## 发布结论

Phoenix Wing **0.6.1** 已于 2026-08-02 按锁步矩阵公开发布。npm 发布身份为
`phoenixwing321`；11 个 scoped packages 全部先于聚合根包发布，并在继续下一包前
逐项查询精确版本。12 个包的 `latest` 标签最终均为 `0.6.1`。

根 `phoenix-wing@0.6.1` 的 Registry manifest 将内部 workspace 依赖正确转换为
`@phoenix-wing/code-core@0.6.1` 与 `@phoenix-wing/db-node@0.6.1`，不含
`workspace:`、`link:` 或 `file:`。发布过程没有重复发布或遗留部分版本。

## 发布前门禁

发布前必须完成且全部成功：

- `pnpm docs:check`；
- `pnpm verify:architecture`；
- `pnpm build` 与 `pnpm verify:aggregate-dist`；
- `pnpm verify:release-matrix`；
- `pnpm test:workspace` 与全 workspace typecheck；
- `pnpm verify:package-tarballs`；
- `pnpm verify:cad-rust-tarball`；
- 无相邻 Wing 源码的干净 Registry 安装与公共入口 smoke。

当前新增的工作台定向测试覆盖 Editor/TabBar 单实例、Header 与非 Header 还原入口、
六类区域隐藏、英文文案、Tab 通用动作、Escape 冲突、overlay 相对层级，以及规范
图标 ID、Host namespace、未知 fallback、Ribbon/Tree 一致呈现、旧注册兼容，以及
light/dark × normal/hover/active 的 Ribbon 语义色和 24px 图标占框/线重边界。

2026-08-01 本地 `pnpm verify:ci` 已退出 0；其中包含 12 个发布单元的版本矩阵、
workspace 测试与类型检查、聚合构建、各包 tarball 干净消费者安装，以及 CAD Rust

规范 `pnw:*` 图标无 fallback，light 主题 normal / active 的 computed color 分别为
`#64748b` / `#1d4ed8`，图标与按钮通过 `currentColor` 一致继承。该结果只证明本地
候选，不等于 Registry 发布。

2026-08-02，将 `origin/develop` 之后的四条 8 月 1 日本地提交合并为单一中文提交；
其 tree 与已验收的 `eb131a4` 完全一致，提交时间沿用原最后一条时间。
用户自行暂存的消费者审计文档没有进入该提交，其工作区内容和 index 状态保持不变。

过期 Token 首次使 `npm whoami` 返回 `E401 Unauthorized`，当时停止在首包之前；
用户更新 Token 后 `npm whoami` 返回 `phoenixwing321`，再从第一个 scoped package
重新开始正式发布。该阻断没有造成 Registry 部分发布。

包，审计为 0 漏洞。`npm ls` 确认根包、`code-core`、`db-node`、Vue、Pinia 和
Element Plus 均解析到预期版本；Node 22 使用发布门禁同款 CSS loader 加载聚合 UI，
验证 `PNW_VERSION === "0.6.1"`、`PnwWorkbenchShell`、`PnwIconRenderer` 与
