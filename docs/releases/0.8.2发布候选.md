## 展示契约

- 一级相邻区块共用全宽分隔、主题标题底色和 16px chevron；二级使用透明标题、轻字重和内缩。
- `icon / title / status / context / actions / body` 六槽，空槽不占宽；操作控件是折叠标题的兄弟节点，不放在按钮内部。
- 只拥有折叠等展示状态；模型、草稿、选择、revision、capability 与动作仍由原组件/宿主管理。程序投影不冒充用户操作。
- 原不可折叠标题保持静态 heading；不额外创造可执行按钮。组件无宿主、网络、文件系统、设置或路由依赖，不创建额外滚动边界。
- 上游领域组件使用显式 `blockPresentation`，默认保留旧呈现。已发布基线不支持的能力不能由消费者伪装成可用。
- 自有示例入口为工作台“内容 Block”页面（`?example=content-block`）；展示六槽、二级、静态标题、窄宽及草稿保留。
