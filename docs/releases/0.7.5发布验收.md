状态：current（2026-09-14 已通过 pnpm 正式发布，Registry exact/latest 均为 0.7.5）

Owner：Phoenix Wing maintainers

适用版本：根包 0.7.5；scoped packages 保持既有独立版本

最后核验：2026-09-14

## 1. 发布集合

本轮只有根 Vue/UI 聚合包发生源码、公共 API 与发布制品变化：

| 发布单元 | 发布版本 | 变化 |
| --- | --- | --- |
| `phoenix-wing` | `0.7.5` | 新增 `PnwTabContainer`，以及浮窗平铺、层叠和 View presentation record 排列 API |

11 个 `@phoenix-wing/*` scoped packages 没有运行时源码、公开 API、制品或内部依赖变化，继续保持
`release-matrix.json` 中的独立版本。根包继续精确依赖 `@phoenix-wing/code-core@0.6.6`
与 `@phoenix-wing/db-node@0.6.3`。

## 2. 能力边界

- `PnwTabContainer` 提供受控活动页签、键盘导航、可访问性关系和首次激活懒挂载；已挂载
  panel 只隐藏不销毁，保留 iframe 与未保存输入。
- `pnwArrangeFloatingViewBounds` 只计算调用方显式指定窗口的平铺或层叠几何，不创建、
  关闭、浮出、收回或聚焦窗口。
- `pnwArrangeViewPresentationRecords` 只更新既有 record 的位置与尺寸，保持 identity、mode、
  revision 和 Portal 实例不变。
- 窄区域优先保证窗口留在可用范围、平铺互不重叠，并显式报告临时压缩后的最小尺寸。
- Host 继续拥有 Router、业务页面清单、窗口生命周期、保存守卫和持久化。

详细接入契约见[《Pnw 通用内部 Tab 与浮窗排列》](../Pnw通用内部Tab与浮窗排列.md)。

## 3. 本地点检与脱敏

- 当前差异未包含 npm Token、密码、私钥、个人邮箱、用户目录或带凭据 URL；
- 文档只使用仓库相对路径、标准命令和通用示例，不记录本机用户名或认证信息；
- 消费者通过同级目录入口使用主 Wing，不向 manifest、lockfile 或 `node_modules` 写入
  `link:`、`file:`、本地 `workspace:` 或依赖 override；
- 发布制品必须由 tarball 门禁继续检查本机路径和 workspace 协议泄漏。

## 6. 隔离 Registry 消费与浏览器

在仓库之外创建临时 Vite/Vue 消费者，精确安装 Registry `phoenix-wing@0.7.5`，
不使用相邻 Wing 源码、`link:`、`file:`、`workspace:` 或 override：

- 干净安装通过；实际 package.json、lockfile、integrity 与上表一致。
- TypeScript 类型检查与 Vite 生产构建通过（1718 modules）。
- 根与子路径入口为同一组件/函数，`PNW_VERSION === "0.7.5"`。
- 浏览器页面自检通过：内部 Tab 首次懒挂载，切回保留同一 input/iframe 节点及未保存输入；键盘跳过禁用 Tab。
- 浮窗层叠、平铺、360px 可用区回归通过，排列前后输入保持，非模态；浅色/深色背景正确。纯几何断言额外覆盖 1100/360/48px 可用区和 record identity/mode/revision 不变。
- 浏览器控制面同时记录到 `MutationObserver.observe` 的目标非 Node 异常；当前未确认来源，不能将本次浏览器点检记成 console 零错误。Wing 源码与 Registry 根包未检索到 `MutationObserver` 使用；这不代替进一步归因。

标题为“Wing 0.7.5 Registry 验证”的页面是本次临时消费者，不是 Wing 正式产品菜单或
已提交的 `examples/` 入口。工程入口为 `index.html` → `main.ts`；在该临时工程执行
`npm run typecheck`、`npm run build`，然后
`pnpm exec vite preview --host 127.0.0.1 --port 49575 --strictPort` 可重跑预览。
该端口不是公共 API；后续可按[内部 Tab 与排列契约](../Pnw通用内部Tab与浮窗排列.md)
另建独立 Registry consumer 复现，不依赖这份临时目录永久存在。

本次发布不代替各产品真实 Host 的 Registry 升级、平台与保存流程回归；也未创建或推送
`v0.7.5` tag。发布后目录整理与本回执先在 working 收口，再按用户授权本地提交、提升主库，不改写已发布 0.7.5 包。
