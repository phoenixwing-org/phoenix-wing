# phoenix-wing 组件改进计划

基于 open-issue 实战反馈，以下组件需要增强封装。

---

## 1. PnwRibbonShell — 内置布局切换 + 工具区

**现状：** 只是一个容器 `<slot />`，布局切换按钮由消费项目自行实现。

**改进：**
- 右侧内置"单行/双行切换"按钮（icon-only，hover 显示）
- 右侧 `slot` 供消费项目插入额外工具按钮
- 布局模式通过 `v-model:layout` 暴露（`"stacked" | "inline"`）

**API 设计：**
```vue
<PnwRibbonShell v-model:layout="ribbonLayout" :collapsed="false">
  <PnwRibbonGroup ... />
  <template #utils>
    <button>自定义按钮</button>
  </template>
</PnwRibbonShell>
```

**文件：** `src/layout/PnwRibbonShell.vue`

---

## 2. PnwWorkbenchTabBar — 内置关闭全部 + 完整样式

**现状：** 只渲染 tab 列表，关闭全部按钮由消费项目自行添加。

**改进：**
- 内置"关闭全部"按钮（`can-close-all` prop 控制显隐）
- 内置"新建 Tab"按钮（`can-add` prop）
- header 模式下完整样式（圆角、动画、阴影）
- tab 区域宽度自适应，溢出滚动

**API 设计：**
```vue
<PnwWorkbenchTabBar
  :tabs="tabs"
  :active-tab-id="activeId"
  :can-close-all="tabs.length > 1"
  in-header
  @select="..."
  @close="..."
  @close-all="..."
  @new-tab="..."
/>
```

**文件：** `src/layout/PnwWorkbenchTabBar.vue`

---

## 3. PnwAppToolbar — 新增（Header 组件）

**现状：** 不存在。消费项目自行实现 header。

**改进：** 提供通用 Header 组件，组合 RibbonTabBar + WorkbenchTabBar + 右侧自定义区。

**API 设计：**
```vue
<PnwAppToolbar
  :ribbon-tabs="[{ id:'issue', label:'Issue' }]"
  v-model:active-ribbon-tab="activeTab"
  :wb-tabs="wbTabs"
  v-model:active-wb-tab="activeWbTab"
>
  <template #brand>Logo / 名称</template>
  <template #actions>
    <el-button>用户</el-button>
  </template>
</PnwAppToolbar>
```

**文件（新建）：** `src/layout/PnwAppToolbar.vue`

---

## 4. PnwSidebarBlock — 增强

**现状：** 功能完整，但缺少默认高度和占位内容。

**改进：** 无需大改。`body-scroll` 模式下内容区自动撑开。

---

## 优先级

| 优先级 | 组件 | 工作量 | 影响 |
|--------|------|--------|------|
| 🔴 P0 | PnwRibbonShell 内置布局切换 | 小 | 消除所有消费项目的重复代码 |
| 🔴 P0 | PnwWorkbenchTabBar 内置按钮 | 中 | 关闭全部/新建按钮无需消费项目写 |
| 🟡 P1 | PnwAppToolbar 新建 | 中 | 统一 Header 模式 |
| 🟢 P2 | PnwSidebarBlock | 小 | 体验优化 |
