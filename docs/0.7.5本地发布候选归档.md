# Phoenix Wing 0.7.5 本地发布候选归档

状态：current（本地归档候选，尚未公开发布）

Owner：Phoenix Wing maintainers

适用版本：根包 0.7.5；scoped packages 保持既有独立版本

最后核验：2026-09-13

## 1. 发布集合

本轮只有根 Vue/UI 聚合包发生源码、公共 API 与发布制品变化：

| 发布单元 | 候选版本 | 变化 |
| --- | --- | --- |
| `phoenix-wing` | `0.7.5` | 新增 `PnwTabContainer`，以及浮窗平铺、层叠和 View presentation record 排列 API |

11 个 `@phoenix-wing/*` scoped packages 没有源码、公开 API、制品或内部依赖变化，继续保持
`release-matrix.json` 中的独立版本。根包继续精确依赖 `@phoenix-wing/code-core@0.6.6`
与 `@phoenix-wing/db-node@0.6.3`。

## 2. 能力边界

- `PnwTabContainer` 提供受控活动页签、键盘导航、可访问性关系和首次激活懒挂载；已挂载
  panel 只隐藏不销毁，保留 iframe 与未保存输入。
- `pnwArrangeFloatingViewBounds` 只计算调用方显式指定窗口的平铺或层叠几何，不创建、
  关闭、浮出、收回或聚焦窗口。
- `pnwArrangeViewPresentationRecords` 只更新既有 record 的位置与尺寸，保持 identity、mode、
  revision 和 Portal 实例不变。
- 窄区域优先保证窗口留在可用范围、平铺互不重叠，并显式报告临时压缩后的最小尺寸。
- Host 继续拥有 Router、业务页面清单、窗口生命周期、保存守卫和持久化。

详细接入契约见[《Pnw 通用内部 Tab 与浮窗排列》](Pnw通用内部Tab与浮窗排列.md)。

## 3. 本地点检与脱敏

- 当前差异未包含 npm Token、密码、私钥、个人邮箱、用户目录或带凭据 URL；
- 文档只使用仓库相对路径、标准命令和通用示例，不记录本机用户名或认证信息；
- 消费者通过同级目录入口使用主 Wing，不向 manifest、lockfile 或 `node_modules` 写入
  `link:`、`file:`、本地 `workspace:` 或依赖 override；
- 发布制品必须由 tarball 门禁继续检查本机路径和 workspace 协议泄漏。

## 4. 本地归档门禁

本地归档前必须全部通过：

- `pnpm install --frozen-lockfile`；
- `pnpm verify:ci`；
- `git diff --check`；
- 当前差异敏感信息扫描；
- 真实 WebView 消费者通过 `pnpm wing` 解析到同级主库并完成 Tab、平铺、层叠与暗色主题回归。

最终测试数量、tarball 结果与本地归档提交在门禁执行完成后记录；任何失败都不得归档为
0.7.5 候选。

## 5. 发布边界

本地提交和同级源码消费不等于 npm Registry 发布。当前任务不执行 `pnpm publish`、Git push
或消费者 Registry 依赖升级；公开发布必须另行授权，并在无相邻 Wing 源码的临时消费者中
完成 exact 安装、manifest 协议检查、类型、生产构建与浏览器回归。
