# 快速使用

```bash
npm install phoenix-wing vue pinia
```

聚合 UI 从编译后的 `dist` 单入口加载。新代码优先使用下列根入口命名导出；0.4.x 仍保留 `.vue` 子路径作为兼容入口，两种写法解析到同一模块实例。

## 工具函数

```ts
import {
  pnwFormatDuration,
  pnwScheduleDebounced,
  pnwBindPointerDrag,
  pnwResolveColorScheme,
  pnwClearPhoenixBrowserStorage,
} from 'phoenix-wing'
```

本地工程应用优先用 `PnwWorkspaceGate` 把 `PnwWorkspaceState` 组合为全屏 Welcome 与
Workbench 入口；默认没有 Workspace 不能进入，关闭后自动回 Welcome。`PnwWorkspaceWelcome`
仍可单独组合。目录选择、验证与持久化继续由 Host/controller 负责。完整接法见
[《Pnw 工作空间欢迎页与最近列表》](Pnw工作空间欢迎页与最近列表.md)。

## 确认对话框

应用根层先且只挂载一个 Host：

```vue
<script setup lang="ts">
import { PnwChoiceDialogHost } from 'phoenix-wing'
</script>

<template>
  <RouterView />
  <PnwChoiceDialogHost />
</template>
```

业务代码只发起请求：

```ts
import { pnwPromptChoice } from 'phoenix-wing'

const result = await pnwPromptChoice({
  title: '确认删除',
  message: '此操作不可撤销',
  choices: [
    { id: 'delete', label: '删除', variant: 'danger' },
    { id: 'cancel', label: '取消' },
  ],
})

if (result.choiceId === 'delete') {
  // 执行删除
}
```

Workbench scheme 变化时由 Host 统一调用 `pnwApplyColorScheme(scheme)`；它会同步所有 Wing
Teleport 浮层。若使用 Element Plus，Host 还需按解析结果切换 `html.dark / --el-*`，插件页面不写
第二套 dark dialog CSS。完整边界见[《浮层主题契约》](Pnw工作台Web浮层主题契约.md)。

多个 Web 都需要完整工作台时，入口优先只组合一个受控壳层：

```vue
<script setup lang="ts">
import { ref } from 'vue'
import {
  PnwWorkbenchShell,
  pnwNavigationFromRibbonTabs,
  type PnwRibbonAppearance,
  type PnwViewBlockVisibility,
} from 'phoenix-wing'
import { productRibbonTabs } from './productRibbonTabs.js'

const nodes = pnwNavigationFromRibbonTabs(productRibbonTabs)
const activeNodeId = ref('dashboard')
const expandedNodeIds = ref<readonly string[]>([])
const treeCollapsed = ref(false)
const editorMaximized = ref(false)
const locale = ref<'zh-CN' | 'en-US'>('zh-CN')
const contributions = { primary: true } as const
const visibility = ref<PnwViewBlockVisibility>({ primary: true, bottom: true, secondary: false })
const ribbonAppearance = ref<PnwRibbonAppearance>({
  mode: 'compact',
  compact: { iconSize: 16, showTitles: true, showGroupLabels: false },
  ribbon: { iconSize: 36, showTitles: true, showGroupLabels: true },
})
</script>

<template>
  <PnwWorkbenchShell
    v-model:expanded-node-ids="expandedNodeIds"
    v-model:ribbon-appearance="ribbonAppearance"
    v-model:tree-collapsed="treeCollapsed"
    v-model:visibility="visibility"
    v-model:editor-maximized="editorMaximized"
    :locale="locale"
    :nodes="nodes"
    :active-node-id="activeNodeId"
    :contributions="contributions"
    @activate="activeNodeId = $event"
  >
    <template #brand>产品品牌</template>
    <main>业务页面</main>
    <template #primary><aside>业务筛选</aside></template>
  </PnwWorkbenchShell>
</template>
```

这个组件只减少 `index.vue` / `App.vue` 对 Header、ActivityBar、TabBar 和 Layout 的重复引用；Router、权限、页面加载、Tab 会话和偏好持久化仍由产品宿主提供。需要不同 Header 或导航结构时，可使用 `header`、`modules`、`pages`、`activity` 等 slot 覆盖，而不必放弃低层兼容组件。

`editorMaximized` 是 Host 受控的瞬时布局状态，不应写进显示偏好；Wing 负责
最大化/还原按钮与 Escape。`locale` 只驱动 Wing 自有的 `zh-CN / en-US` 文案，
Host 继续持有语言持久化。刷新当前标签和关闭其他标签可分别用
`canRefreshActiveTab / canCloseOtherTabs` 开启，再监听同名动作事件。

页面需要自行贡献 Primary / Secondary / Bottom 时，可由 consumer 创建隔离 registry，Shell 直接动态装配当前 View 的组件：

```ts
import {
  pnwCreateViewContributionRegistry,
  usePnwRegisteredViewContribution,
  usePnwViewContribution,
  type PnwViewBlockComponentContributions,
} from 'phoenix-wing'

export const productViewRegistry =
  pnwCreateViewContributionRegistry<PnwViewBlockComponentContributions>()

// 在业务 View 的 setup 中调用；停用或卸载时自动释放。
usePnwViewContribution(productViewRegistry, () => props.workbenchTabId, {
  primary: { component: ProductPrimary, props: () => ({ filter: filter.value }) },
  secondary: { component: ProductProperties },
  bottom: {
    component: ProductProblems,
    tabs: () => problemTabs.value,
  },
})

// 在宿主中按活动 View/Tab 读取，并传给 <PnwWorkbenchShell :view-blocks="viewBlocks">。
const viewBlocks = usePnwRegisteredViewContribution(
  productViewRegistry,
  activeTabId,
  {},
)
```

registry 只管理 contribution 的身份与生命周期，不拥有 Router、权限、业务状态或持久化。已有命名 slot 仍可覆盖动态组件，便于消费者渐进适配。

## 工作台引擎

```ts
import { pnwCreateWorkbench } from 'phoenix-wing'

const wb = pnwCreateWorkbench({
  pagePolicy: (pageId) => ({ maxTabs: 1, tabEnabled: true }),
  navLabel: (pageId) => pageId,
})

wb.openTab({ pageId: 'my-page', title: '我的页面' })
```
