# Phoenix Wing 0.7.0 发布验收

状态：current（已发布）

Owner：Phoenix Wing maintainers

适用版本：0.7.0

最后核验：2026-08-21

## 候选范围

0.7.0 是根 Vue/UI 包的向后兼容框架能力候选。版本提升到新的 minor，反映本轮同时新增
完整 View 呈现、Workspace Welcome/Home、工作空间控制器与信息卡片组等较大公共能力；
当前不主动移除 0.6.x 公共入口。
本轮新增受控的可浮动 / Primary 停靠工具宿主。
同时新增不含搜索或自由输入语义的 `PnwSelect`，供紧凑 Header 与普通枚举表单复用。
并新增非模态 View 对话框的纯 TypeScript Host 契约；Tauri/Web adapter 仍由消费者实现，
不会给根包增加 Tauri 运行时依赖。
本轮还加入本地工程工作空间的 Host 中立控制器、受控资源访问端口与注入式 Tauri
command adapter；Wing 不直接选择目录、读写本机路径或持久化介质。
根 `phoenix-wing` 从 0.6.4 提升到 0.7.0；11 个未变化的 `@phoenix-wing/*` scoped
packages 继续保持 0.6.3，根包对 `code-core` / `db-node` 的精确内部依赖也保持 0.6.3。

本轮实际发布集合只有 `phoenix-wing@0.7.0`；11 个 scoped packages 均保持 0.6.3。
2026-08-17 已完成 Registry 发布与两个本地工作台消费者的 Registry 回归。Git push 与 tag
继续由开发者手工完成，不属于 npm Registry 成功判定。

## 公共能力

- `PnwDockableToolDefinition / State / Command`；
- `PNW_DEFAULT_DOCKABLE_TOOL_STATE`；
- `pnwNormalizeDockableToolState / pnwReduceDockableToolState`；
- `pnwIsDockableToolVisible`；
- `PnwDockableToolWindow / PnwDockablePrimarySection`；
- `PnwIcon` 新增 `window-float` 公共图标；
- 新增 `phoenix-wing/assets/phoenix-wing-mark.svg` 稳定静态导出；
  `PnwPhoenixWingMark` 与 favicon/静态复制均使用这一权威几何真源。
- `zh-CN / en-US` 停靠、浮出、首尾与关闭文案。
- `PnwSelect / PnwSelectOption / PnwSelectSize`，含 24px compact、32px default、
  Teleport 主题菜单和完整键盘/ARIA 契约。
- `PnwViewDialogRequest / Capabilities / Outcome / HostAdapter / Controller`；
- `PNW_DEFAULT_VIEW_DIALOG_SIZE`、`pnwCreateViewDialogController` 与请求/呈现工具函数。
- `PnwPresentationFrameDefinition`：Tool/View 共用 movable、轴向 resize、推荐/min/max
  尺寸、rememberBounds 与 closeBehavior 声明；生命周期仍由两个 owner adapter 分开。
- `PnwViewPresentationContribution / Record / Command / PortalHandle`、纯 reducer 与
  `PnwViewPresentationPortal`：Header/Main target-ready 后按 revision 原子迁移；普通稳定
  owner View 默认可浮出，Home/无 owner/显式 false 自动禁用。
- Editor MRU manager/selector、owner Tab `keep / hide-when-floating` 投影、单实例
  `preferredPresentation:floating` open command 与统一 `PnwFloatingWindowMenu`。
- `PnwViewPresentationLeaseRegistry`：原子 commit、延迟空宿主回收、owner rollback/dispose、
  stale generation 防护和 floating record HMR 恢复。
- `PnwPageHeader` 为 detachable View 自动提供最右侧浮出/收回按钮；业务 action 不再逐页
  复制图标、Tooltip、ARIA 或暗色样式。
- `PnwFloatingPanel` 新增八向/轴向 resize、键盘操作、推荐尺寸恢复、受控 bounds 与活动
  视觉；`pnwCreateFloatingWindowStack` 统一 pointer/focus 置顶、活动窗 Escape 与焦点恢复。
- 新增 `presentation` overlay layer（1600）：完整 View 与 dockable Tool 默认位于 Workbench
  Header 之上、modal 之下；共享 stack 会归一历史不同 base，保证跨类型点击置前。
- `PnwWorkspaceDescriptor / Capability / Phase / Failure` 与
  `pnwCreateWorkspaceController`：统一 open/switch/close、only-latest、AbortSignal、失败回滚
  和 participant 生命周期。
- `PnwWorkspaceResourcePort / PnwRecentWorkspaceStore / PnwWorkspaceStorage`、
  `pnwNormalizeWorkspaceRelativePath` 与 `pnwCreateWorkspaceResourceRef`：只允许工作空间相对
  资源，不接受绝对路径或 `..` 越界。
- `pnwCreateTauriWorkspaceAdapter`：只接收 Host 注入的 picker/invoke/command 名称，不引入
  Tauri 依赖；纯 Web 不伪造本地绝对路径能力。
- `PnwWelcomeShell / PnwRecentWorkspaceList / PnwWorkspaceWelcome`：把受控
  `PnwWorkspaceState` 呈现为响应式欢迎页和最近列表；产品通过 slot 提供品牌、链接和条目
  扩展，Wing 不选择目录或持久化介质。
- `PnwWorkspaceGate`：默认 required 的全屏 Workspace 入口，统一返回、关闭、打开成功后进入
  与关闭成功后回 Welcome；optional 明确允许无 Workspace 模式。`actionPlacement=auto` 在有
  Rail 时把生命周期动作放入左侧入口区，无 Rail 时移到页眉；所有投影只发出同一受控关闭意图。
- `PnwWorkspaceGate / PnwWorkspaceWelcome` 接收受控 `colorScheme`，在 Workbench 外建立
  canonical 主题根；消费者不再复制主题类或暗色 CSS。
- Workspace Welcome 打开、返回与关闭入口共享中性 `.pnw-workspace-entry-action`；默认不使用
  大面积强调色，light/dark/system 正文对比度不低于 4.5:1，并统一 hover/focus/disabled。
- `PnwColorSchemeToggle / pnwToggleColorSchemeWithTransition`：受控 light/dark/system 切换、
  24px currentColor 太阳/月亮、默认 380ms 圆形揭示，并在 reduced-motion、无 API 或动画失败时
  直接更新；Host 仍拥有主题应用与持久化。
- `PnwRecentWorkspaceList` 的扩展操作、compact 类型选择、打开箭头和移除按钮统一垂直中心；
  窄屏只换行，不再形成整高空白分栏。
- `PnwWorkspaceWelcome / PnwWorkspaceGate` 增加可选最近区域折叠：默认继续常开，支持
  `recentDefaultOpen` 非受控初值或受控 `recentOpen / update:recentOpen`，不改变 Workspace 数据；
  折叠模式与信息 Block 共享壳层视觉，条目改为外壳内分隔行以避免双重卡片。
- `PnwInformationBlock` 提供 JSON/DTO 驱动的中立可折叠信息外壳与 header/item/footer slots；
  JSON 读取、字段语义和业务动作仍由 Host 拥有。
- `PnwInformationCardGroup` 接收中立卡片组 DTO，统一 auto-fit、`8px 12px`
  外围 inset、8px gap、主题、ARIA 与默认不可折叠卡片；消费者无需复制
  grid、断点或逐卡片模板。第二个本地工作台消费者已实测通过宽屏双列、
  窄屏单列、gap 与默认 inset，且无私有 grid/media/`:deep`/padding 补丁。
- `PnwWorkspaceRailAction` 与 `#secondary-actions` 统一 Welcome 左 Rail 的次级命令：打开入口、
  次级命令、生命周期动作按固定层级排列；按钮文字和行为继续由 Host 定义。
- `PnwChoiceDialogHost` 在动态请求打开或替换后实际聚焦默认安全动作，Tab 保持在对话框内，
  关闭或 Escape 后恢复原触发元素；不再依赖动态 `autofocus` 的浏览器时序。
- `PnwWorkspaceTypeSelect` 与 `pnwNormalizeWorkspaceTypes`：提供 mixed/code/cad/lighting
  默认顺序，并允许 Host 追加或重排稳定类型 ID。
- `PnwWorkbenchHome / pnwCreateWorkbenchHomeDefinition`：普通 Home View 的中立壳体和注册
  元数据；不决定 Router、自动打开或 Tab 关闭策略。

## 隐私与公开边界

- 根包作者统一为 `PhoenixWing contributors`；当前发布制品不携带个人主目录、真实邮箱、
  凭据或非公开消费者名称。
- 测试中的邮箱使用 `.invalid` 保留域；fixture 与文档只使用中立业务数据。
- Desk Tools 可作为公开提炼来源出现；其他消费者统一写成“第二个本地工作台消费者”或
  “第三方消费者”，不记录产品名、仓库路径、提交号或领域字段。
- scoped 包中既有 LICENSE / NOTICE 与兼容领域说明属于历史权利和来源边界，本轮不以隐私
  清理为由删除，也不因此空升未变化包版本。
- 最终 `pnpm pack` / clean consumer 门禁后仍须检查 tarball 文件清单和解包内容，不能只审查
  Git 工作树。

## 发布回执与后续核对

1. `release-matrix.json` 仅根包为 0.7.0，11 个 scoped packages 保持 0.6.3；
2. pack manifest 不含 `workspace:`、`file:`、`link:`，内部依赖转换为精确 0.6.3；
3. clean consumer 可导入 `PNW_VERSION === "0.7.0"`、新增组件、View/Tool 状态机、Workspace
   controller 与类型；
4. 2026-08-21 再次只读查询确认 Registry 已包含 exact `phoenix-wing@0.7.0`；
5. Desk Tools 与第二个本地工作台消费者已完成候选复验；最终单提交只需保持同一 tree 并由
   消费者精确锁定新 SHA 做最小回归。两边均确认默认取消动作获得焦点、取消后恢复到原
   Workspace 入口，且没有产品级 querySelector/nextTick 补丁；
6. 0.7.0 已完成 npm 发布；后续 push 和 tag 仍由开发者手工管理。
