# phoenix-wing

TypeScript 纯工具库，从 phoenix-desk-tools 提取的可复用逻辑。

## 安装

```bash
npm install phoenix-wing
```

## 使用

```ts
import { asyncProgress, scheduleDebounced, colorScheme } from 'phoenix-wing'
```

## 开发

```bash
npm install
npm run build
npm test
```
